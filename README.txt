Rahmah Fashion – Netlify ডিপ্লয় গাইড
1. এই ফোল্ডারটি GitHub-এ আপলোড করুন (বা zip-টি Netlify "Import from Git" দিয়ে ব্যবহার করুন)।
   দ্রষ্টব্য: netlify/functions ও Blobs চালু রাখতে Git/CLI ডিপ্লয় দরকার; শুধু drag-and-drop-এ ফাংশন কাজ নাও করতে পারে।
2. Netlify → Site configuration → Environment variables → ADMIN_PASSWORD নামে আপনার গোপন পাসওয়ার্ড দিন → Redeploy।
3. অ্যাডমিন: https://আপনার-সাইট/admin.html
4. ডোমেইন: Domain management → Add custom domain। HTTPS স্বয়ংক্রিয়।
